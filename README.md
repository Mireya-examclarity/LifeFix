# LifeFix



### What is this?

It's a Python web application that tries to solve small daily life annoyances.

We as humans waste too much time doing little things manually, such as organizing tasks and deadlines, calculating bills and splitting them with friends, and planning our schedules.

LifeFix aims at solving some of these small problems as a digital todo list with a twist.



### The idea

While most other sites give you information on what you could do, I want to give you an idea of what to do next.
The main question was: What small annoyances in everyday life could be improved using software?
I wanted to make something useful while also making it fun to use. That's where the Outer Orbit theme comes in!!!.


### What it can do

> It can create tasks with deadlines, estimated hours and according to priority.
> It can calculate task priority based on deadlines, importance and hours.
> It will suggest which task to do next.
> The website split bills between friends.
> It has space-themed design with an Outer Orbit look.
> It is able organize tasks with a planet-inspired theme.
>It will display NASA's Astronomy Picture of the Day.
> It can track the International Space Station.
> The website provide fallback data if space APIs are unavailable.
> It is simple to use with no login required.
